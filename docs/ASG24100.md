# 一、序列编辑

> 自由方波模式下使用。基本函数库包含方波生成、自定义序列编辑、序列拼接三类函数。

## 1.1 方波生成函数 `Square_Gen`

**功能**：生成基础方波序列。

```python
w1 = Square_Gen(Period, Width, Mode=UP, Loop=1)
```

| 参数 | 必选/可选 | 类型 | 说明 |
|------|-----------|------|------|
| `Period` | 必选 | 正整数 | 方波周期，单位 ns，精度 1ns，范围 1 ~ 2³²-1 |
| `Width` | 必选 | 正整数 | 方波脉冲宽度，单位 ns，精度 1ns，范围 0 ~ 2³²-1 |
| `Mode` | 可选 | 枚举 | `UP`=先低后高，`DOWN`=先高后低 |
| `Loop` | 可选 | 正整数 | 方波循环次数，默认 1，范围 0 ~ 2³²-1 |

**返回**：序列对象，可供 `Seq_Join` / `ASG_SEQ` 使用。

**示例**：
```python
w1 = Square_Gen(16, 8, Mode=UP)
```

---

## 1.2 自定义序列编辑函数 `Seq_Gen`

**功能**：自定义多电平序列，交替指定电平与持续时间。

```python
w1 = Seq_Gen(Level1, Time1, Level2, Time2, ..., Leveln, Timen, Loop=1)
```

| 参数 | 必选/可选 | 类型 | 说明 |
|------|-----------|------|------|
| `Level1` ~ `Leveln` | 必选 | 枚举 | `H`=高电平，`L` |
| `Time1` ~ `Timen` | 必选 | 正整数 | 电平持续时间，单位 ns，精度 1ns，范围 0 ~ 2³²-1 |
| `Loop` | 可选 | 正整数 | 循环次数，默认 1，范围 1 ~ 2³²-1 |

**返回**：序列对象。

**示例**：
```python
w1 = Seq_Gen(H, 1600, L, 300, H, 100)
w2 = Seq_Gen(L, 1600, H, 300, H, 100, Loop=10)
```

---

## 1.3 序列拼接函数 `Seq_Join`

**功能**：将多个序列拼接成一个新序列。

```python
w4 = Seq_Join(Seq_Gen1, Seq_Gen2, ..., Seq_Genn)
```

| 参数 | 必选/可选 | 类型 | 说明 |
|------|-----------|------|------|
| `Seq_Gen1` ~ `Seq_Genn` | 必选 | 序列对象 | 由 `Seq_Gen` / `Square_Gen` 生成的序列 |

**返回**：拼接后的序列对象。

> ⚠️ **注意**：生成的基本序列长度须满足 4×n（单位 ns），不足自动补零。

**示例**：
```python
w4 = Seq_Join(W1, W2, W3)
```

---

## 1.4 `ASG_SEQ` 类型

**功能**：将序列组合为可受触发控制的播放序列，子序列按时间先后排列，外部触发模式下受触发信号控制。

```python
s1 = ASG_SEQ([w1(重复次数), ..., wn(重复次数)])
```

| 参数 | 说明 |
|------|------|
| `w1` ~ `wn` | n 个序列对象（n ≥ 1） |
| `重复次数` | 正整数，最大 2¹⁶-1。外部触发模式下表示触发延迟值 |

**返回**：`ASG_SEQ` 对象，可传给 `ASG_ADVS`。

**示例**：
```python
s1 = ASG_SEQ([w2(40), w3(2)])          # 2 个子序列
s2 = ASG_SEQ([w1(5000), w2(2), w3(1)]) # 3 个子序列
s3 = ASG_SEQ([[w1(5), w2(2)], w3(1)])  # 2 个子序列（嵌套）
s4 = ASG_SEQ([[w1(5), w2(2)], [w3(1), w4(100)]])
```

---

## 1.5 `ASG_ADVS` 类型

**功能**：高级序列容器，支持 `+` / `+=` 运算合并多个 `ASG_SEQ`。

```python
a1 = ASG_ADVS()
a1 += s1(3) + s2(2)
```

| 参数 | 说明 |
|------|------|
| `s1`, `s2` ... | `ASG_SEQ` 对象（括号内数字为重复次数） |

**返回**：`ASG_ADVS` 对象。

**示例**：
```python
a1 = ASG_ADVS()
a1 += s1(3) + s2(2)
a2 = ASG_ADVS(s1(3) + s2(2))  # 与 a1 等效
a3 = s1(3) + s2(2)            # 自动类型转换，与 a1 等效
```

---

## 1.6 `ASG_OUT[n]` 类型

**功能**：绑定序列到硬件输出通道。n 取值 1 ~ 8，对应 8 个输出通道。

```python
ASG_OUT[1] = s1
```

> 常高电平由软件界面控制。

---

## 1.7 `Counter_En[n]` 类型

**功能**：用于 Counter 计数（仅内部触发模式）。n = 1 或 2，对应计数通道 1 / 2。可将 `ASG_SEQ` 序列赋值给它。

# 附录：错误码说明

> 来源：《ASG24100 SDK 使用说明》中 `QMCResult` 枚举定义。

## 返回值约定

| 返回值 | 含义 |
|--------|------|
| `1` (`QMC_OK`) | 执行成功 |
| 负数 | 错误，可通过 `ASG_GetErrorInfo(code)` 获取具体错误描述 |
| 大于 1 的整数 | 警告（非致命，操作可能部分成功或存在注意事项） |

## 错误码表

| 错误码 | 名称 | 说明 | 建议操作 |
|--------|------|------|----------|
| `-1` | `QMC_ERROR` | 一般性错误，如设置失败、数据获取失败等 | 重新操作 |
| `-300` | `QMC_ERROR_ASG_LIBUSB_COMMON` | libusb 执行错误 | 检查 USB 连接 |
| `-301` | `QMC_ERROR_ASG_INITLIBUSB_FAILED` | libusb 初始化失败 | 重新初始化 SDK |
| `-302` | `QMC_ERROR_ASG_INITUSBLIST_FAILED` | 初始化设备列表失败 | 检查设备连接 |
| `-303` | `QMC_ERROR_ASG_OPENDEV_FAILED` | 设备打开失败 | 确认设备在线 |
| `-304` | `QMC_ERROR_ASG_EXTERNAL_INPUT` | 外部输入异常 | 检查外部触发信号 |
| `-305` | `QMC_ERROR_ASG_DOWNLOAD_BUSY` | 设备下载正忙 | 等待下载完成 |
| `-306` | `QMC_ERROR_ASG_WAVECODE_DOWNLOAD_FAILED` | ASG 波形数据下载失败 | 检查波形代码格式 |
| `-307` | `QMC_ERROR_ASG_WAVEPARSER` | ASG 波形解析失败 | 需先运行 asgparser/copy_to_appdata.bat |
| `-308` | `QMC_ERROR_ASG_CHANNEL_UNITNUMS_OUTRANGE` | ASG 波形数据中单元个数超出范围 | 检查波形序列长度 |
| `-309` | `QMC_ERROR_ASG_CHANNEL_WAVEDATA_LESSTHAN_NORMAL` | ASG 波形数据过短 | 检查波形数据完整性 |
| `-310` | `QMC_ERROR_ASG_WAVEPARSER_OUTOFBOUNDS` | 解析出的波形数据超出范围 | 检查波形参数 |
| `-311` | `QMC_ERROR_ASG_CYCLE_LEVEL` | 通道周期或高电平异常 | 确保周期 > 高电平宽度 |
| `-312` | `QMC_REEOR_ASG_DEVICE_NO_EXIST` | 发送指令时，指定的设备 id 不存在 | 确认设备编号正确 |
| `-313` | `QMC_ERROR_ASG_ISPLAYING` | 当前设备正在播放，相关设置无法进行 | 先停止播放再设置 |
| `-314` | `QMC_ERROR_ASG_COMPILE_Illegal` | 当前编译模式不支持该操作 | 检查 CompileMode 设置 |

## 警告码表

| 警告码 | 名称 | 说明 |
|--------|------|------|
| `300` | `QMC_WARNING_ASG_CYCLE_LEVEL_CHANGED` | 因周期或高电平大小关系，另一参数被自动修改 |

## 使用示例

```python
result = ASG_SetParamInt(dev, "/Device/PlaybackState", 1)
if result == 1:
    print("播放成功")
elif result < 0:
    err = ASG_GetErrorInfo(result)
    print(f"错误 {result}: {err}")
    # 根据错误码做不同处理
    if result == -313:
        ASG_SetParamInt(dev, "/Device/PlaybackState", 0)  # 先停止
        ASG_SetParamInt(dev, "/Device/PlaybackState", 1)  # 再播放
else:
    print(f"警告: 返回值 {result}")
```

# 附录：常用参数指令表

> 配合 `ASG_SetParamInt` / `ASG_GetParamInt` / `ASG_SetParamFloat` / `ASG_GetParamFloat` 使用。24 个通道使用 `C1`~`C24` 区分，下表以通道 1 为例。

## 常规参数

| 指令 | 类型 | 说明 |
|------|------|------|
| `/Waveform/CompileMode` | int | 编译模式：0=连续方波，1=自由方波 |
| `/Device/ChildCard1/OutputLevel` | int | 输出电平：0=3.3V，1=5V |
| `/Device/ChildCard1/Impedance` | int | 匹配阻抗：0=50Ω，1=1MΩ |
| `/Device/IN1/ClockIn` | int | 时钟源：0=内部，1=外部10M，2=外部100M，3=外部可变时钟 |
| `/Device/TriggerSwitch` | int | 触发模式：0=外部，1=内部 |
| `/Device/TriggerEdge` | int | 触发沿：0=上升沿，1=下降沿 |
| `/Device/TriggerWaitTime` | int | 触发超时：0~1s，单位 ns |
| `/Device/PlaybackState` | int | 播放状态：0=停止，1=播放 |
| `/loop` | int | 播放次数（自由方波）：0=一直循环 |
| `/Waveform/PlayMode` | int | 播放模式：0=连续方波，1=自由方波 |

## 通道参数（以 C1 为例）

| 指令 | 类型 | 说明 |
|------|------|------|
| `/Device/C1/Output` | int | 通道使能：0=关，1=开 |
| `/Device/C1/Cycle` | int | 通道周期（外部可变时钟时单位为倍数，其余为 ns）。须 > 高电平宽度 |
| `/Device/C1/HighlevelDuration` | int | 高电平宽度（同上单位）。须 < 周期 |
| `/Device/C1/Delay` | int | 粗延时（单位同上）。须先粗后细，两者都要发 |
| `/Device/C1/SlightDelay` | float | 细延时，单位 ns |
| `/Device/C1/AlwaysHighlevel` | int | 常高电平：设置后通道恒输出高电平，优先级最高 |

> 通道 2~24 将 `C1` 替换为 `C2`~`C24` 即可。
